# Web App Structure

- app/(dashboard): Enterprise overview and KPIs
- app/archive-explorer: hierarchical archive browsing
- app/ai-command-center: AI operations and automation controls
- app/workflows: approval chain management
- app/compliance: law & ISO monitoring center
- app/analytics: predictive and operational analytics
- app/organization: hierarchy & RBAC administration

UI standards:
- TailwindCSS + shadcn/ui components
- Dark/light mode
- i18n: Arabic/French/English
- WCAG accessibility baseline
